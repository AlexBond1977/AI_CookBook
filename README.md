# 🍳 CookBook

Учебный проект: веб-приложение для поиска и просмотра рецептов.
Frontend на чистых HTML/CSS/JS, backend на Express.

> **Учебный проект.** Создан в рамках домашнего задания при помощи ИИ.
> Не предназначен для production-использования.

---

## Что внутри

```
AI_CookBook/
├── cookbook-be/   # backend на Express: API рецептов, in-memory хранилище
└── cookbook-fe/   # frontend на ES-модулях: список, поиск, избранное, история
```

- 📄 [cookbook-be/README.md](./cookbook-be/README.md) — эндпоинты, данные, запуск backend'а.
- 📄 [cookbook-fe/README.md](./cookbook-fe/README.md) — архитектура, поток данных, дизайн, запуск frontend'а.

## Быстрый запуск

Нужны **два терминала** — backend и frontend работают одновременно.

**Терминал 1 — backend:**
```bash
cd cookbook-be
npm install
npm start          # → http://localhost:3001
```

**Терминал 2 — frontend:**
```bash
cd cookbook-fe
npx serve          # → http://localhost:3000
```

Откройте `http://localhost:3000` в браузере.

> Frontend использует ES-модули (`<script type="module">`) — они не работают
> по протоколу `file://`, поэтому нужен статический сервер. `npx serve` —
> самый простой вариант.

## Что умеет приложение

- Список рецептов с обложками, категориями и временем приготовления.
- Поиск по названию с дебаунсом 300 мс.
- Фильтр по категории.
- Избранное с оптимистичным обновлением UI.
- Блок Recently Viewed, обновляющийся при просмотре рецепта.
- Страница рецепта: ингредиенты, инструкция, управление избранным.
- Адаптивная сетка: 3 / 2 / 1 карточки в ряд.

---

## Ограничения

- Данные backend'а — **в памяти**: избранное и история сбрасываются при
  перезапуске сервера.
- Приложение рассчитано на **одного пользователя**.
- Роутинг упрощённый: переключение экранов в состоянии, без изменения URL.
- **GitHub Pages не используется**: Pages раздаёт только статику и не может
  запустить Node.js-бэкенд.
